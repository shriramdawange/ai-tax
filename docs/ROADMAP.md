# AI TAX — Build Roadmap

## Phase 1 — Financial core

- Organization and financial periods
- Chart of accounts
- Customers/vendors
- Transaction model
- Double-entry journal engine
- Ledger
- Trial balance
- Profit & loss
- Balance sheet
- Accounting invariants and audit trail

## Phase 2 — Documents and invoices

- Secure document storage
- OCR provider abstraction
- Invoice extraction
- Sales/purchase transaction proposals
- Duplicate detection
- Source-to-entry traceability

## Phase 3 — Banking

- CSV/XLSX/PDF import
- Transaction normalization
- Matching engine
- Bank reconciliation
- Exception center

## Phase 4 — GST

- GST transaction model
- Versioned GST rules
- ITC engine
- GSTR-1 preparation
- GSTR-3B preparation
- GSTR-2B reconciliation

## Phase 5 — TDS

- TDS rule engine
- Applicability
- Deductions and liabilities
- Challan tracking
- Return preparation

## Phase 6 — ITR

- Taxpayer profile
- Tax computation engine
- Tax information reconciliation
- Form selection/mapping
- ITR preparation and validation

## Phase 7 — AI accountant

- Natural-language transactions
- Controlled agent tools
- Autonomous low-risk processing
- Explanation/evidence layer
- Risk scoring and exception handling

## Phase 8 — Official filing adapters

- GST/GSP adapter
- TDS adapter
- Income Tax/ERI adapter
- Authentication and authorization flows
- Submission status and verified acknowledgement
