# AI TAX

Autonomous Indian accounting, GST, TDS and ITR compliance platform.

## Vision

AI TAX turns business financial data into a traceable accounting and compliance workflow: documents and bank transactions are ingested, transactions are classified, double-entry accounting is generated, reconciliations are performed, and GST/TDS/ITR preparation is produced from a single financial source of truth.

## Architecture principles

- AI interprets; deterministic engines calculate.
- Money is stored as exact decimal values, never floating point.
- Every accounting/tax number is traceable to source records.
- Posted journals are immutable; corrections use reversal/adjustment workflows.
- Government filing is separated behind replaceable official integration adapters.
- No fake government API responses or fabricated filing status.
- Sensitive filing actions require the authorization required by the official mechanism.
